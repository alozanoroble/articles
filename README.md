## Provenance

`papers/index.csv` records, for every file, the exact URL it came from, the dates compared to choose that version, its size and a SHA-256 checksum.

These are author versions throughout — my own website copies or the arXiv copies — never a publisher's typeset PDF.

### Choosing the newer version

The website's HTTP `Last-Modified` header cannot be used to rank versions: a bulk re-upload on 2024-06-25 reset it to the same value for every PDF on the server, which would make every website copy look newer than every arXiv copy. What gets compared instead is the date each PDF carries *internally* (`ModDate`, falling back to `CreationDate`) against the arXiv entry's `updated` timestamp.

Of the 37 articles, 14 are currently taken from arXiv.
